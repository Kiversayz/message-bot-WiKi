# Telegram Confluence Bot

Телеграм-бот для чтения статей корпоративной вики Confluence прямо в Telegram. Демонстрационная версия работает с одной заданной статьёй, поддерживает пагинацию и закладки с привязкой к конкретной странице.

Проект универсален и разворачивается в любой организации через настройки в `.env`.

## Стек технологий
- Python 3.12, aiogram 3.x
- SQLAlchemy 2.0 + aiosqlite
- aiohttp, beautifulsoup4, markdownify
- Confluence REST API

## Команды бота

| Команда | Назначение |
|---------|-----------|
| `/start` | Приветствие и список команд |
| `/article` | Чтение статьи с пагинацией |
| `/bookmarks` | Список сохранённых закладок |
| `/sync` | Обновление статьи из Confluence |

## Ключевые возможности

- **Пагинация** — длинные статьи разбиваются на страницы ~600 символов с навигацией инлайн-кнопками.
- **Закладки с привязкой к странице** — сохранение конкретной страницы статьи для быстрого возврата.
- **Кэширование в БД** — контент хранится в SQLite, бот не дёргает Confluence при каждом чтении.
- **Версионность** — синхронизация сверяет номер версии в Confluence и обновляет контент только при изменениях.
- **Адаптивный парсинг** — конвертация XHTML Confluence (макросы кода, стили, списки) в Telegram-совместимый HTML.

## Логика работы

1. Администратор запускает `main.py` — скрипт запускает бота, создает БД если нет.
2. Пользователь отправляет `/article` — бот мгновенно отдаёт закэшированную статью, разбитую на страницы.
3. Навигация по страницам происходит через редактирование одного сообщения, если нет сохраненной статьи то необходима команда `/sync`.
4. Текущую страницу можно добавить в закладки одной кнопкой.
5. Команда `/bookmarks` выводит список сохранённых страниц с прямыми ссылками для открытия.

## Примечания

- Текущая версия — MVP для одной статьи (ID задаётся в `.env`).
- Для работы с несколькими статьями требуется навигация по пространствам и поиск.
- SQLite выбран для простоты развёртывания; для production — PostgreSQL.
- FSM-состояния хранятся в памяти (MemoryStorage); для мультинстанс-развёртывания нужен Redis.
