# Telegram Confluence Bot

Телеграм-бот для чтения статей корпоративной вики Confluence. Позволяет просматривать, искать и навигировать по документации прямо в интерфейсе Telegram. 

Проект универсален и может быть развернут в любой организации путем настройки параметров подключения в файле `.env`. Основная цель — предоставить сотрудникам удобное мобильное пространство для чтения корпоративных знаний.

## Стек технологий
- Python 3.12
- aiogram 3.x
- PostgreSQL, Redis
- Docker, Docker Compose
- Confluence REST API

## Структура проекта

```text
confluence_bot/
├── bot/                        # Логика Telegram-бота
│   ├── handlers/               # Обработчики команд, сообщений и callback-запросов
│   ├── keyboards/              # Фабрики и разметка клавиатур (inline/reply)
│   ├── middlewares/            # Промежуточные обработчики (логирование, доступы)
│   └── states.py               # FSM-состояния для многошаговых диалогов
│
├── services/                   # Бизнес-логика и интеграции с внешними системами
│   └── confluence/             # Модуль интеграции с Confluence REST API
│       ├── client.py           # Асинхронный HTTP-клиент для запросов к API
│       └── parser.py           # Конвертер XHTML-формата Confluence в HTML Telegram
│
├── core/                       # Инфраструктурные компоненты и настройки
│   ├── config.py               # Загрузка и валидация переменных окружения (.env)
│   ├── database.py             # Настройка подключения к PostgreSQL
│   └── redis.py                # Настройка подключения к Redis
│
├── models/                     # ORM-модели (схема таблиц базы данных)
├── migrations/                 # Скрипты миграций схемы БД (Alembic)
├── utils/                      # Вспомогательные утилиты и общие хелперы
│
├── docker-compose.yml          # Оркестрация контейнеров (бот, БД, кэш)
├── Dockerfile                  # Инструкция для сборки образа бота
├── .env.example                # Шаблон с необходимыми переменными окружения
├── requirements.txt            # Зависимости проекта
└── main.py                     # Точка входа в приложение (инициализация и запуск)
```

## Установка и запуск

1. Клонируйте репозиторий.
2. Создайте файл `.env` на основе `.env.example` и заполните его данными (токен бота, URL Confluence, PAT-токен, credentials БД и Redis).
3. Запустите контейнеры:
   ```bash
   docker-compose up -d
   ```

## Функциональность
- Навигация по пространствам (Spaces) и страницам Confluence.
- Полнотекстовый поиск по вики с использованием CQL.
- Адаптивное отображение контента (парсинг макросов, кода, списков).
- Сохранение закладок и истории просмотров.
- Кэширование запросов для снижения нагрузки на Confluence API.
